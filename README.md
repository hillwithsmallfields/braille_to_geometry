Braille to geometry
===================

There are various converters between ASCII text and Unicode Braille
characters; instead, this one converts ASCII text to the geometrical
patterns of dots, suitable for output as SVG and incorporation into
diagrams, maps etc.

This currently only handles letters, spaces, and newlines.  There's
plenty still to do, including handling the UniCode braille cell
characters (in progress).  Also, I should document it properly.
